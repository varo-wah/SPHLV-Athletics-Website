## Manager entry rules

- Enter one completed match per row in rows 5–104.
- Use real date and time cells.
- Enter whole-number scores from 0 to 999.
- Put `SPH LV` in exactly one of Home Team or Away Team. Opponent names remain free text.
- Leave unfinished matches blank; do not add status, result, fixture, or standings columns.

## Access and publication

The intended manager access is **Anyone with the link — Editor**. This is an accepted operational risk: anyone receiving a forwarded edit link can alter official scores. Google revision history remains the recovery mechanism.

Each `Results` tab must also be published separately as read-only CSV. The website consumes only those published CSV URLs; managers use the native edit links.
